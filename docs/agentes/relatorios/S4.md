## Decisões que tomei
- Utilizei `body::before` com `position: fixed` e 3px de altura para a faixa de gradiente do pôr do sol no topo, evitando adicionar elementos DOM extras que pudessem quebrar seletores CSS ou scripts de layout.
- No logotipo, o gradiente `--grad-vice` foi aplicado via `-webkit-background-clip: text` e `-webkit-text-fill-color: transparent` na palavra "Clipper", mantendo o fallback `color: var(--accent)` para compatibilidade.
- No player de vídeo, o valor `#000000` foi mantido pontualmente como cor de fundo para letterboxing natural do vídeo nativo.
- O trabalho foi desenvolvido em worktree isolado (`L:\Fast-Clipper-S4`) com variáveis temporárias apontando para `data\_tmp`, preservando o diretório principal `L:\Fast-Clipper-Publico` e o disco `C:`.
