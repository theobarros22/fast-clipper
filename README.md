# Fast Clipper

Projeto independente em desenvolvimento para criar clipes de transmissões ao vivo e vídeos gravados, com revisão, enquadramento vertical e suporte futuro a equipes.

Esta base inicial deriva do Viral Cutter Classic. O plano de produto está em [docs/plano-fast-clipper.md](docs/plano-fast-clipper.md). A integração de lives, contas e publicação ainda precisa ser implementada e validada; esta cópia inicial não é uma versão pronta para produção.

Os testes previstos incluem lives gravadas de GTA V obtidas com autorização. Mídias, credenciais e dados pessoais não devem ser enviados ao repositório. Este projeto é independente e não tem associação com Rockstar Games ou Take-Two Interactive.
